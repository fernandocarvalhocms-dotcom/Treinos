# Controle de Aulas

PWA simples para registrar aulas de:
- Tênis: terça e quinta
- Academia: quarta e sexta

## Recursos
- Geração automática das aulas do mês
- Status: Teve / Não teve / Pendente / Reposição
- Campo de observação
- Quem cancelou
- Valor por aula configurável
- Fechamento automático mensal
- Histórico por mês
- Armazenamento local no aparelho
- Backup exportável/importável em JSON
- Compartilhamento do fechamento
- Funciona offline depois da primeira abertura
- Instalável na tela inicial do iPhone/Android

## Publicar no GitHub Pages

1. No repositório, abra **Settings > Pages**.
2. Em **Build and deployment**, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
3. Salve.
4. O GitHub mostrará o endereço publicado após o deploy.

## Instalar no iPhone
1. Abra o endereço publicado pelo Safari.
2. Toque em **Compartilhar**.
3. Escolha **Adicionar à Tela de Início**.
4. Confirme em **Adicionar**.

## Instalar no Android
1. Abra o endereço publicado no Chrome.
2. Menu ⋮
3. **Instalar app** ou **Adicionar à tela inicial**.

## Observação importante
Os dados ficam armazenados localmente no navegador do aparelho. Use **Exportar backup** periodicamente se quiser segurança adicional.
